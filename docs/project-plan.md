# Auto Shop Management System

## Project Overview

A full-stack web application designed to help automotive repair shops manage daily operations, including vehicle repairs, customer records, employee activity, invoices, and finances.

## Project Goals

- Develop a functional web application.
- Create a centralized database for shop records.
- Allow employees to manage repairs and invoices.
- Provide shop owners with financial and operational insights.
- Implement secure employee authentication and activity tracking.
